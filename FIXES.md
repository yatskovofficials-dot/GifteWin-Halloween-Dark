# Исправления сборки GifteWin RANDOM

- Исправлена критическая ошибка рулетки: в предыдущей сборке отсутствовали `WHEEL_PRIZES` и `WHEEL_COLORS`, из-за чего экран рулетки падал при отрисовке.
- Добавлены призовые сектора и согласован размер SVG-подписей с диском рулетки.
- Центральный значок рулетки теперь доступен с клавиатуры и имеет понятную подпись для экранных помощников.
- Добавлена очистка таймера при уходе со страницы.

Проверки после правок: JavaScript проходит `node --check`; Python-файлы бота проходят `compileall`.
